How we got here

    Package explorer

    Click a paragraph to see its WordprocessingML. Deleted text appears in Reviews and Raw parts; this is a text projection, not a Word layout preview.
    Select a paragraph.
    Package parts point to other parts through relationship IDs. External targets are displayed as text and never fetched.
    Parsed comments and common tracked-change elements from the main document. Additional review metadata is always available in Raw parts.
    

    What you’re looking at
    DOCX is an Open Packaging Conventions ZIP package. The main document contains paragraphs (w:p), runs (w:r), and text nodes (w:t). Styles, numbering, metadata, and embedded media live in separate parts. .rels files connect those parts. There is no single XML file that represents every part of a DOCX.
